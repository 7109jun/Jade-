##  만든 이유 (Why Jade?)

**저는 XML의 태그(`< >`)가 정말 끔찍해서 이 포맷을 만들었습니다.**

개발자라면 누구나 한 번쯤 겪어봤을 그 고통:
- `<name>Alice</name>` 처럼 같은 단어를 두 번씩 타이핑하는 비효율 ⌨️💦
- 닫는 태그(`</>`)를 잊어버려서 발생하는 끝없는 파싱 에러 🐛
- 데이터보다 **문법 태그**가 더 많은 파일 가독성 😵‍💫

Jade는 이 모든 불편함을 없애기 위해 설계되었습니다.
- ✅ **태그 제거**: `< >` 없이 `key : value`로 깔끔하게
- ✅ **닫기 기호 간소화**: 복잡한 `</tag>` 대신 점(`.`) 하나로 블록 종료
- ✅ **본질에 집중**: 데이터 자체에만 눈을 돌릴 수 있는 최소한의 문법

**Jade는 XML의 복잡함을 버리고, 데이터의 순수함만 남겼습니다.** 💎

##  주요 특징

-  **타이핑 60% 감소**: 불필요한 따옴표, 쉼표, 중괄호, 태그 제거
-  **뛰어난 가독성**: 인덴트와 간단한 기호(`:`, `-`, `.`)로 구조 표현
-  **양방향 변환**: JSON ↔ Jade 완전 호환 (데이터 손실 별로 없음)
-  **게임 개발 최적화**: 아이템 목록, 캐릭터 상태, 설정 값 저장에 이상적

##  Quick Start

### 1. 기본 문법

    # 주석은 #으로 시작합니다
    name : Alice
    level : 10
    <isAlive>/          # true
    <isDead>;           # null

### 2. 객체와 배열

    player :
        name : Knight
        hp : 100
        
        items :
            - Sword
            - Shield
        .
    .

### 3. JSON vs XML vs Jade 비교

같은 데이터를 세 가지 포맷으로 표현했을 때의 차이입니다.

| 포맷 | 예시 | 특징 |
|------|------|------|
| **XML** | `<name>Alice</name>` | 태그 반복으로 타이핑량 많음 |
| **JSON** | `"name": "Alice",` | 따옴표와 쉼표로 인해 번거로움 |
| **Jade** | `name : Alice` | **최소한의 키 스트로크로 명확한 표현** |
